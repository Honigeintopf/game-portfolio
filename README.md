# Game-Portfolio

Statische Seite (eine `index.html`, Bilder und Videos in `assets/`), live unter https://games.feurigebu.de (GitHub Pages, CNAME in Route 53).

Lokal ansehen: `python3 -m http.server 8765`, dann http://localhost:8765 öffnen.

- Videos laden erst beim Klick (youtube-nocookie), vorher nur das Vorschaubild aus `assets/video/`.
- Spiel-Artworks kommen aus `jayplay-website/public/games`, App-Icons aus dem App Store.
